# 网关模块 (Gateway)

这是"蜚"平台的前线接入节点，使用 Go 语言实现，负责处理与端点的通信。

## 技术架构

- **前线网关 (go_gateway)**: 无状态运行，仅作为流量解密中转站
- **NATS 总线 (nats_bus)**: 实现与控制面的物理隔离

## 核心职责

1. 通过 mTLS 1.3 与端点建立安全连接
2. 实现 36 字节包头的流式解包（处理粘包、断包）
3. 对数据进行 ChaCha20-Poly1305 解密
4. 动态计算和附加随机 padding_len 的垃圾数据
5. 将合规数据打包为事件对象发布至 NATS 总线

## 安全特性

- 强制使用 mTLS 1.3 双向认证
- 应用层采用 ChaCha20-Poly1305 全流加密
- 通过随机填充实现抗特征混淆
- 不合规数据包会被立即断开连接
