# 控制面模块 (Control Plane)

这是"蜚"平台的核心控制逻辑，使用 Go 语言实现，负责会话管理和任务调度。

## 技术架构

- **Go 核心 (go_core)**: 实现会话持久化、任务队列调度等功能
- **编译器工作器 (compiler_worker)**: 负责动态编译端点组件

## 核心职责

1. 会话持久化管理
2. 任务队列调度
3. 异步编译网关通信
4. 从内部模板库动态生成端点代码
5. 实现控制流平坦化混淆

## 安全特性

- 通过 NATS 与前线网关实现物理隔离
- 自动化混淆流水线确保每次生成的端点都不同
- 即使前线网关被攻破，核心数据依然安全
