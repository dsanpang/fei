# 端点模块 (Agents)

这是"蜚"平台的受控端模块，负责在目标机器上持久化部署并维持与控制中心的通信。

## 技术架构

本模块采用双层架构设计：
- **主内核 (x64_asm)**: 使用纯 x64 NASM 编写，负责与网关保持 TLS 连接和解析 36 字节包头
- **执行沙箱 (rust_no_std_sandbox)**: 使用 Rust no_std 编写的隔离执行环境，运行远程下发的功能组件

## 核心职责

1. 与 Go 网关保持 TLS 连接以维持心跳
2. 解析 36 字节包头，处理 ChaCha20 解密
3. 在隔离沙箱中执行远程下发的功能组件
4. 向控制中心报告执行状态

## 安全特性

- 物理体积小于 15KB
- 通信与执行彻底分离
- 即使插件执行失败也不会影响主内核
