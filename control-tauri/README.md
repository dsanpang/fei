# 控制端模块 (Control-Tauri)

这是"蜚"平台的操作控制端，使用 Tauri + Vue3 技术栈构建，为用户提供图形化操作界面。

## 技术架构

- **Tauri 核心 (tauri_core)**: 使用 Rust 实现，确保高算力安全与本地内存数据混淆
- **Vue 前端 (vue_frontend)**: 使用 Vue 3 + Vite 构建响应式大屏拓扑

## 核心职责

1. 提供多用户协同操作界面
2. 渲染网络拓扑图
3. 实现插件加密打包驱动
4. 与 Go Core 通过 gRPC 进行强类型契约通信

## 安全特性

- 敏感凭证通过 Rust 调用系统密钥环加密存储
- 使用 gRPC 进行强类型安全通信
- 本地数据通过内存混淆保护
